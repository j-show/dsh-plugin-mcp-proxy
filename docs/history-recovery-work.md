# A4 历史恢复工作契约

本页细化[现有 A4](acceptance.md#待完成事项)，是后续开发导航，不表示历史恢复已完成，也不新增重启后继续旧 MCP 操作的能力。需求依据 B10/B11、B15/B16、B18/B19/B21/B28。

| 子项 | 实现/检查入口 | 必须验证的行为 |
| --- | --- | --- |
| A4.1 输入及轮次绑定 | agent/src/index.ts 的 mcp-proxy/input、turn 事件及归约器 | 会话重开/fork 保留过去的设备和目录事实；新轮次重新绑定；缺失绑定拒绝本地访问，不从历史恢复活连接权限 |
| A4.2 sampling 记录 | agent/src/sampling.ts、Session 事件及附件 | 记录已接收输入、实际模型与终态；回放不再次调用模型；父取消取消活请求，历史仍可读 |
| A4.3 elicitation 历史投影 | agent/src/elicitation.ts、host/src/elicitation.ts、ui 的 elicitation-controller | pending → accepted/declined/cancelled/expired/unavailable 等语义按实际协议结果表达；父终止、续接丢失或重启后展示不可继续及原因，不恢复原始副作用 |
| A4.4 回答及送达 | host 的原子回答结算与 UI 状态 | 多标签页只接受一次答案；答案已接受但送达不确定时保留 unknown，不重新提交初始工具 |
| A4.5 SDK 兼容 | 固定 DSH 的 Session 类型/持久化、公共 TS/Python SDK | 四事件完整写入/读回、未知必需事件拒绝不变；只补白名单不构成此项完成 |
| A4.6 无密钥快照 | agent/UI 相关测试和专用输出快照 | 成功、协议错误、断线未知、设备切换、回调历史的用户/模型视图可重建；URL 认证材料、cookie、私钥和访问令牌不进入快照 |

所有相对实现入口位于 `packages/dsh-plugin/src/`。具体事件载荷须在实现前对照当前类型和历史设计逐字段确认：身份/父调用、连接代际、目录修订、请求模式、时间与终态及可公开内容。复用已记录事实，不复制秘密，也不通过改变原事件含义读取旧记录。

每个子项先补失败用例，再做最小修改；保存序列化样本和实际读回证据。真实 SDK 回放、重启和用户界面仍须独立验收。若固定公共 SDK 不能表达必要事实，先记录兼容限制及方案，不能自动扩大补丁或静默弱化必需事件。
